Product Launch Platform (Inspired by Product Hunt)
A full-featured product launch platform inspired by Product Hunt, built using the MERN stack (MongoDB, Express.js, React, Node.js).

This platform allows users to discover, upvote, review, and discuss the latest tech products. It also features role-based authentication, moderation tools, reporting systems, and search functionality with pagination. Admins can manage products, users, and coupons through a dedicated dashboard.

Key functionalities include:

User authentication & authorization (JWT-based)

Product submission, review, and voting

Admin dashboard for product, user, and coupon management

Payment integration for premium features

Search, filtering, and pagination for better UX

Tech Stack: React, Node.js, Express, MongoDB, JWT, Tailwind CSS, Stripe .
